AgentMail Scheduling Agent

Signed email events become verified Cal.com bookings through a durable, fail-closed workflow.

Booking authority

Cal.com owns availability and creates the booking. The model proposes an action, but deterministic code checks slots and controls the mutation.

Durable transaction

Each email thread has one serialized state machine with checkpoints before replies and booking creation. Uncertain results are quarantined.

Cross-provider verification

The confirmation is sent only after Cal.com and Google Calendar agree on the booking identity, time, content, attendees, and Meet link.
